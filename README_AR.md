# نظام حضور المندوبين — الإصدار 2.0.2

هذا النظام يعمل من الموقع وتطبيق Android واحد. المندوب ينشئ حسابه من تبويب «حساب جديد»، ثم ينتظر موافقة الأدمن. بعد التفعيل يستخدم الحساب من جهازه الموثوق، ولا يتم قبول الحضور أو الانصراف إلا عند وجود الهاتف داخل نطاق المخزن الذي يحدده الأدمن من الخريطة.

## روابط التشغيل

الموقع الإنتاجي: https://delivery-attendance.vercel.app/

رابط APK الموقّع: https://delivery-attendance.vercel.app/delivery-attendance-v2.apk — الإصدار 2.0.2

ملف الإصدار الذي يفحصه التطبيق: https://delivery-attendance.vercel.app/version.json

## حساب الأدمن الابتدائي

اسم المستخدم: `rasim1010`

كلمة المرور الابتدائية: `20203030`

غيّر كلمة المرور مباشرة من قسم «الإدارة» أو «الموقع» بعد أول دخول، ولا تشاركها مع المندوبين.

## الإعداد الأول للمخزن

1. سجّل دخول الأدمن.
2. افتح قسم «الموقع».
3. اضغط على المكان الصحيح في الخريطة، أو استخدم موقع الهاتف الحالي، أو أدخل خط العرض والطول يدويًا.
4. اختر نطاق السماح بالمتر من 25 إلى 500 متر، مثل 100 متر.
5. اضغط «حفظ إعدادات المخزن».

يتم التحقق من GPS، دقة الموقع، الاتصال، حالة الموقع الوهمي، وموقع الجهاز على الخادم. وقت تسجيل الحضور والانصراف يعتمد على توقيت الخادم لا ساعة الهاتف. لا يمكن إنشاء سجل حضور ثانٍ إذا كان للمندوب سجل مفتوح في اليوم نفسه.

## إدارة المندوبين

المندوب ينشئ الحساب من جهازه. الحساب يظهر في «بانتظار الموافقة» ولا يعمل قبل موافقة الأدمن. بعد التفعيل يظهر ضمن المندوبين النشطين. النظام يمنع تكرار اسم المستخدم، ويسجل محاولات الدخول الفاشلة، ويربط أول جهاز موثوق بالحساب.

إذا حاول فتح حساب مندوب من جهاز آخر، تُسجل محاولة أمنية ويظهر تنبيه داخل لوحة الأدمن فقط، مع اسم المندوب والوقت والجهاز والموقع التقريبي. يستطيع الأدمن اعتماد الجهاز الجديد أو حظره وإعادة ضبط الجهاز الموثوق. توجد حماية من الجلسات المتزامنة للحساب نفسه.

## التقارير والإدارة

قسم «الحضور» يدعم البحث باسم المندوب، التاريخ من وإلى، فلتر الحالة، جدولًا يوميًا، تفاصيل السجل، مدة الدوام، وحالة «لم يسجل خروجًا». توجد أزرار تصدير Excel وطباعة التقرير. قسم «الإدارة» يحتوي على الإجازات والملاحظات، سجل التدقيق، حالة Firebase، إصدار التطبيق، وفحص التحديث. قسم «الإشعارات» مخصص لتنبيهات الجهاز الثاني.

## الأمان والبنية الخادمية

تم تفعيل Firebase Authentication بالبريد وكلمة المرور مع خدمة خادمية تربط اسم المستخدم بحساب Firebase. في الإصدار 2.0.2 أصبحت قائمة المندوبين تتحدث لحظيًا بعد إنشاء الحساب، ويظهر الحساب في تبويب «بانتظار الموافقة» دون الحاجة إلى إعادة تشغيل لوحة الأدمن. كما تم حصر فحص وتنزيل تحديث APK داخل التطبيق الأصلي فقط؛ الموقع لا يعرض بطاقة تنزيل APK. عمليات التسجيل وتسجيل الدخول والحضور والانصراف الحساسة تمر عبر API على Vercel. تمت إضافة قواعد Firestore مقيدة تمنع الكتابة المباشرة للحضور والحسابات الحساسة، وتسمح للأدمن والمندوب بالحد الأدنى المطلوب فقط.

مفتاح Firebase Admin موجود كمتغير Secret داخل Vercel فقط، وغير موجود في GitHub أو APK أو حزمة المصدر. لا تضعه داخل مجلد `www` أو ترسله إلى أي شخص.

## تثبيت APK والتحديث الأونلاين

نزّل `delivery-attendance-v2.apk` من رابط APK، فعّل السماح بالتثبيت من هذا المصدر عند طلب Android، ثم ثبّت التطبيق. يحتاج التطبيق إلى الإنترنت وGPS وصلاحية الموقع.

تحديثات الواجهة تصل مباشرة من Vercel. إذا تم إصدار APK جديد، يعدّل المطور `version.json` ويرفع APK الجديد إلى نفس الرابط أو رابط جديد، ثم ينشر الموقع. التطبيق يفحص `version.json` من قسم «الإدارة» ويعرض رابط تنزيل الإصدار الجديد. Android سيطلب تأكيد التثبيت؛ لا يتم التحديث الصامت من دون Google Play.

## بناء إصدار جديد

المشروع يستخدم Capacitor. بعد تعديل الواجهة، نفّذ:

```bash
cp index.html manifest.json icon-192.png icon-512.png version.json www/
pnpm exec cap copy android
cd android
./gradlew assembleRelease
```

يجب استخدام نفس مفتاح توقيع Android الموجود خارج GitHub حتى يقبل الهاتف التحديث فوق النسخة الحالية. لا تغيّر `applicationId` ولا تفقد ملف مفتاح التوقيع أو كلمة مروره؛ فقدان المفتاح يمنع إصدار تحديث فوق النسخة المثبتة.

## الملفات الحساسة

المشروع يستبعد `.secrets/` ومفتاح التوقيع وملفات كلمات المرور من GitHub وVercel. حزمة المصدر المسلّمة للمطور لا ينبغي أن تتضمن هذه الملفات. احتفظ بملف بيانات توقيع Android في مكان خاص وآمن.

## اختبار التشغيل

اختبر على هاتفين Android على الأقل: إنشاء حساب مندوب، موافقة الأدمن، تسجيل الدخول داخل النطاق، رفض التسجيل خارج النطاق، تغيير الجهاز، تنبيه الجهاز الثاني، نسيان تسجيل الخروج، التصدير، وفحص التحديث. دقة GPS تختلف حسب الهاتف والمبنى، لذلك يجب اعتماد موقع المخزن بعد تجربة فعلية في مكان العمل.
